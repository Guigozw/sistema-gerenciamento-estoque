# Sistema de Gerenciamento de Estoque

## Sobre o projeto

O Sistema de Gerenciamento de Estoque é um projeto acadêmico desenvolvido como parte das atividades do curso de Análise e Desenvolvimento de Sistemas (ADS) do Instituto Federal do Piauí (IFPI).

O objetivo é desenvolver um sistema que facilite o controle de produtos em estoque, permitindo organizar informações, acompanhar quantidades disponíveis e registrar movimentações de entrada e saída.

## Objetivos

- Facilitar o cadastro e a consulta de produtos.
- Controlar as quantidades disponíveis no estoque.
- Registrar entradas e saídas de produtos.
- Reduzir erros no controle manual de estoque.
- Organizar as informações de maneira eficiente.

## Funcionalidades previstas

- [ ] Cadastro de produtos.
- [ ] Consulta e listagem de produtos.
- [ ] Edição e exclusão de produtos.
- [ ] Registro de entrada de produtos.
- [ ] Registro de saída de produtos.
- [ ] Consulta da quantidade disponível em estoque.
